# Mark's Repository
Paul's specs, dimensions, angles, part counts, and costing rules for real builds.
Fed by Paul over time. Every entry kept as he gives it.

## Rules
- Rectangular frame, e.g. 300 x 200: two pieces at 300, two pieces at 200 = four pieces per frame.
- Paul thinks in 3D. Part counts repeat per side.
- Stock length = sum of parts + waste.
