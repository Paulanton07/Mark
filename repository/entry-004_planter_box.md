# entry-004 — Planter Box (Paul's own design)

**Client:** Paul (parent). Commission, 2026-10-10.
**Source:** /workspace/plan/build_planter_box_v2.py  →  planter-box-v2.pdf
**Status:** v2 delivered to Paul 2026-10-10 (6 A4 pages, inline images).
**Supersedes:** the invented "Slatted Planter Box" (build_planter_box.py, content 367117087547592704) — that design (corner posts + slat walls) is NOT Paul's. His is stacked frame rings held between four legs.

## Paul's spec (his words + photo)
- Frame ring: 2 long planks **800 × 80 × 23** run OUTSIDE; 2 short planks **400 × 80 × 23** captured INSIDE, butt against the longs. Outer footprint **800 × 446** (400 + 2×23).
- Screwed **from outside**, through the long into the short end grain. **60 mm** screws.
- Four corner legs, **600 long**, each **two planks** glued + screwed → 46 thick. Legs **screwed from the inside** of each corner with **35 mm** screws (short, so they grip but do not break through the 46).
- Legs run the FULL height (600 = o/a). Trough nests in the TOP of the legs, rim flush with the leg tops. No stand.
- Two products, same footprint: **3 rings deep (240 trough)** and **2 rings deep (160 trough)**. Same legs both.

## The fixings (Paul's correction 2026-10-10)
- Frames: 60 mm, from outside.
- Legs: 35 mm, from inside each corner so they can't break through.
- Untreated timber only (food bed).

## Open / assumed
- Floor: not specified by Paul. Drawn as 3 boards across the bottom ring with drainage gaps + liner. Assumed.
- Leg cross-section drawn 80 × 46 (two 80-wide planks face-to-face). Photo read as edge-to-edge, but face-to-face reads more sensible for a post; flagged to Paul, he confirmed the screw side not the lamination direction.
- Liner (geotextile) + wood oil outside: my call, carried from the feeder guide.

## Latest revision — v6 (2026-10-10, Paul's day-off review)
**Source:** /workspace/plan/build_planter_box_v6.py  →  planter-box-v6.pdf (6 A4 pages).
- **v4:** Paul corrected leg/frame layering — LEGS on the OUTSIDE at the corners (outer posts, full height, proud/flush at the rim), frame ring set INSIDE between them. Long 800 planks run the full length behind the corners and show only between the legs.
- **v5:** Paul's screw tip — use smooth-shank (part-threaded) screws on every two-plank joint (legs, rebate rails): the smooth top turns in the first plank while the thread bites the second, so it clamps. Fully-threaded screws jack the planks apart.
- **v6:** (a) picture-sequence tile 7 had the rebate rail running ACROSS the corner legs — fixed so the rail sits in from the outer face, BETWEEN the legs, matching tile 8; (b) NEW build step — after laying the nine 400 boards, **sew the floor**: screw from OUTSIDE, through the long plank just above the rebate, into the CENTRE of each board end, nine screws down each long side, so the boards lock and can't drop out when the box is flipped. Re-emphasised: legs flush with the top, joints pulled tight, minimal gaps (water rot).

## Final build order (Paul, verbatim recap)
Build upside down → stack the frames (2 or 3 as needed) → legs on the outside at each corner, flush with the top → screw legs from inside the corners (35 mm) → rebate rails underneath → flip the box over → lay nine 400 boards across the bottom → sew: nine screws a side from outside, just above the rebate, into the centre of each board.
